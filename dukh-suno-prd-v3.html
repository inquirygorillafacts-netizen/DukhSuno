01 — Overview

Vision & Product Overview

DukhSuno ek aise jagah hai jahan koi apna dukh share kar sake — completely anonymously — aur dusra usse sun ke earn kar sake. Premium, safe, no real identity.

🎯
Core Idea

Har insaan ke paas koi na koi dukh hai. Therapist mehenga hai. Dost thak jaate hain. DukhSuno ek marketplace hai jahan trained sunne wale apna time bechte hain aur sunane wale safe jagah paate hain baat karne ke liye — bilkul anonymous, bilkul secure.

📱
Platforms

Web App (Next.js): Full responsive website. PWA installable.
Android App: Expo React Native. EAS cloud build.
iOS App: Same Expo codebase. App Store.

Teeno ek hi Next.js backend se connected. Ek GitHub repo — Monorepo.

ℹ️
Naming Convention in this PRD "Sunane Wala" = jo apna dukh share karna chahta hai (buyer). "Sunne Wala" = jo sun ke earn karta hai (seller/listener).

10 — Credits

Credit Wallet System

💰
How Credits Work

Credits = prepaid balance in user's account. 1 Credit = ₹1.

User PayU se credits add karta hai (₹100/₹250/₹500/custom). Credits kisi bhi listener ke kisi bhi plan mein use ho sakte hain.

Priority rule: Jab bhi payment hogi — available credits pehle use honge, baaki PayU se.

Credits non-refundable (except missed call auto-refund).

🔄
Missed Call Auto-Refund

Agar listener 60 seconds mein call accept nahi karta:

1. Session status → "missed"
2. Used credits auto-restore to user's wallet instantly.
3. If PayU payment was made (no credits) → refund initiate via PayU API (3-5 business days).
4. User ko notification: "Aapka ₹100 wapas aa gaya 💰"
5. Wallet transaction history mein "Refund — Missed call" entry.

16 — Call Tech

WebRTC + react-native-callkeep

lib/webrtc.ts — Core (Web + Mobile)TypeScript
const ICE = [
  { urls: 'stun:stun.l.google.com:19302' },
  { urls: 'stun:stun1.l.google.com:19302' },
  { urls: 'turn:relay.metered.ca:80',
    username: process.env.NEXT_PUBLIC_METERED_USER,
    credential: process.env.NEXT_PUBLIC_METERED_PASS },
]

// CALLER: Create offer, write to RTDB
export async function startCall(sessionId: string): Promise<RTCPeerConnection> {
  const pc = new RTCPeerConnection({ iceServers: ICE })
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true, video: false })
  stream.getTracks().forEach(t => pc.addTrack(t, stream))
  pc.onicecandidate = e => {
    if (e.candidate) push(ref(rtdb,`calls/${sessionId}/callerCandidates`), e.candidate.toJSON())
  }
  const offer = await pc.createOffer()
  await pc.setLocalDescription(offer)
  await set(ref(rtdb,`calls/${sessionId}/offer`), {type:offer.type,sdp:offer.sdp})
  return pc
}

// CALLEE: Read offer, write answer
export async function answerCall(sessionId: string): Promise<RTCPeerConnection> {
  const pc = new RTCPeerConnection({ iceServers: ICE })
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true, video: false })
  stream.getTracks().forEach(t => pc.addTrack(t, stream))
  const offerSnap = await get(ref(rtdb,`calls/${sessionId}/offer`))
  await pc.setRemoteDescription(new RTCSessionDescription(offerSnap.val()))
  const answer = await pc.createAnswer()
  await pc.setLocalDescription(answer)
  await set(ref(rtdb,`calls/${sessionId}/answer`), {type:answer.type,sdp:answer.sdp})
  return pc
}

import crypto from 'crypto'

export async function POST(req: Request) {
  const { amount, userId, type, listenerId } = await req.json()
  // type: "credit_reload" | "direct_session"
  
  const txnid = `DS_${Date.now()}_${userId.slice(0,6)}`
  const key   = process.env.PAYU_KEY!
  const salt  = process.env.PAYU_SALT!
  
  const hashStr = `${key}|${txnid}|${amount}|DukhSuno|User|anon@dukhsuno.app|||||||||||${salt}`
  const hash = crypto.createHash('sha512').update(hashStr).digest('hex')
  
  return Response.json({

}

import twilio from 'twilio'
import { decryptPhone } from '@/lib/crypto'   // AES decrypt stored phone

export async function POST(req: Request) {
  const { listenerEncryptedPhone, sessionId } = await req.json()
  
  const client = twilio(process.env.TWILIO_SID, process.env.TWILIO_TOKEN)
  const phone = decryptPhone(listenerEncryptedPhone)  // decrypt server-side only
  
  await client.calls.create({
    to: phone,
    from: process.env.TWILIO_NUMBER!,
    twiml: `<Response>
      <Say voice="Polly.Aditi" language="hi-IN">
        Namaskar! DukhSuno app mein aapko ek call aa rahi hai.
        Kripya apna DukhSuno app kholen aur call accept karen.
        Aapki kamai aapka intezaar kar rahi hai.
      </Say>
    </Response>`,
  })
  
  return Response.json({ triggered: true })
}
// NOTE: listenerEncryptedPhone is stored AES-256 encrypted in Firestore
// Only decrypted on server during wake-up. Never sent to client.
